# Selling Guide — Curio Maker

Everything you need to list this template. **Delete the whole `marketing/` folder
before you ZIP the product** — it is for you, not the buyer.

## 1. Before you upload — pre-flight checklist

| ✅ | Check |
|---|---|
| ☐ | Delete `marketing/` from the product folder |
| ☐ | Delete `.claude/` (dev config) and any `.zip` files |
| ☐ | Open all 9 pages, click every nav link, confirm nothing 404s |
| ☐ | Click through all 5 themes on 2–3 pages |
| ☐ | Test on a real phone, not just a resized browser |
| ☐ | Run the HTML through [validator.w3.org](https://validator.w3.org) |
| ☐ | Open DevTools Console on each page — zero errors |
| ☐ | Confirm `documentation/index.html` opens and every sidebar link jumps |
| ☐ | ZIP the folder — the ZIP should contain ONE top-level folder, not loose files |

**ZIP structure reviewers expect:**

```
curio-maker.zip
└── curio-maker/
    ├── index.html … 404.html
    ├── assets/
    ├── documentation/
    ├── README.md
    ├── CHANGELOG.md
    └── LICENSE.txt
```

## 2. Images you need to create

You cannot list without these. Use `marketing/preview-sheet.html` — open it in
Chrome and screenshot the bordered blocks.

| Image | Size | What it shows |
|---|---|---|
| **Thumbnail** | 590 × 300 | Name + "9 pages · 5 themes". Must be readable when tiny. |
| **Main preview** | 1180 wide, any height | Stitched screenshots of all 9 pages, top to bottom. |
| **Theme showcase** | 1180 wide | The same hero in all 5 themes side by side — this is your strongest asset, put it second. |

**How to capture full-page screenshots:** open a page in Chrome → `F12` →
`Ctrl/Cmd + Shift + P` → type "screenshot" → *Capture full size screenshot*.

**How to stitch:** paste them into Figma, Canva or Photopea, stack vertically on a
1180 px wide canvas, export as JPG at 80% quality.

> Order matters. Put your **best-looking page first** and the **theme showcase
> second**. Most buyers decide in the first two images.

## 3. Live demo

**Required on ThemeForest, roughly doubles conversion everywhere else.**

Fastest route: drag the product folder onto
[netlify.com/drop](https://app.netlify.com/drop). Free, no account needed for the
first deploy, live in about 30 seconds. Rename the site to something like
`curio-maker-demo.netlify.app`.

Make sure the demo has the theme switcher visible — letting buyers click through
the 5 themes themselves is the whole pitch.

|---|---|
| ThemeForest | **$19–29** — regular licence |
| Gumroad / Creative Market | **$24–39** |

The 5 themes and the dark mode justify the upper end. Do not price below $16 —
buyers read very cheap templates as low quality, and it caps your income per
sale for the life of the item.

## 7. After you list

- **Reply to every comment within 24 hours.** Response time is weighted in
  marketplace search ranking, and buyers mention it in reviews.
- **Ask for a rating** in the documentation footer — already done for you.
- **Ship an update within 60 days.** Even a small one. "Last updated" is visible
  to buyers and a stale date kills sales. Log it in `CHANGELOG.md` and bump the
  version.
- **Ideas for v1.1** that cost little and add listing bullets:
  a Coming Soon page, an RTL version, one more colour theme, a second home-page
  hero variant.

## 8. Common rejection reasons — and where you stand

| Reason | Status |
|---|---|
| Too few pages | ✅ 9 pages |
| No documentation | ✅ Full HTML docs |
| Invalid HTML | ⚠️ Run the W3C validator yourself before submitting |
| Console errors | ✅ Verified clean |
| Poor mobile layout | ✅ Verified at 375 px and 390 px |
| Unlicensed assets | ✅ Only OFL fonts and emoji; no photos |
| Generic / templated design | ✅ Custom mascot, distinctive style |
| Broken links | ✅ Verified — all internal links resolve |
| Placeholder text left in | ⚠️ Demo content is intentional, but check for anything embarrassing |
