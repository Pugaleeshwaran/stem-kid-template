Curio Maker v1.0.0

A nine-page HTML template for kids’ STEM, robotics and coding clubs — with five built-in colour themes and a scroll-animated hero.

Thank you for buying Curio Maker. This document covers everything you need to make the template your own. Nothing here requires a build step, a framework, or Node.js — it is plain HTML, CSS and JavaScript.

What you need to know

Basic HTML. If you can find a heading in a file and type over it, you can customise this template. No JavaScript knowledge is required for normal content edits.

What is included

9 pagesHome, About Us, Products, Pricing, Gallery, Blog, Blog Post, Contact, 404

Quick start

  1. Unzip the folder. Everything lives inside one folder — keep it together.
  2. Double-click index.html. It opens in your browser. That is the whole setup — there is nothing to install.
  3. Open the folder in a code editor. VS Code is free and works well.
  4. Edit the text in the .html files, save, and refresh your browser.
Recommended: use Live Server In VS Code, install the “Live Server” extension, then right-click index.html → Open with Live Server. Your browser then refreshes automatically every time you save.
One thing that needs a server Opening files directly with file:// works for everything except the theme memory (it is stored per-page instead of shared). On a real web host, or via Live Server, this works normally. Nothing else is affected.

All colour lives in one file: assets/css/themes.css. Nothing else in the template contains a hard-coded colour, so changing that one file recolours the entire site — including the robot mascot.

Setting a permanent theme

Visitors can switch themes with the 🎨 button. To ship your site with one fixed theme instead, add data-theme to the <html> tag of every page:

<html lang="en" data-theme="jungle">

To remove the switcher entirely, delete the <div class="themer">…</div> block near the bottom of each page.

Changing a theme’s colours

Each theme is one block of ten colours. Change the hex codes and save:

:root[data-theme="jungle"]{
  --ink:#12261b;      --ink-rgb:18,38,27;   /* text + all outlines   */
  --ink-soft:#4a6353;                       /* secondary text        */
  --cream:#f3f7e6;    --cream-rgb:243,247,230;  /* page background   */
  --white:#ffffff;                          /* card surface          */
  --deep:#12261b;                           /* footer / stats band   */
  --on-deep:#f3f7e6;  --on-deep-rgb:243,247,230;
  --on-accent:#12261b;                      /* text on bright fills  */
  --veil:rgba(18,38,27,.74);                /* lightbox backdrop     */

  --grape:#2f7a4f;    /* primary accent  */
  --sky:#2f9ec4;      /* secondary       */
  --sun:#ffc93c;      /* buttons, badges */
  --coral:#cf5630;    /* highlights      */
  --mint:#8ed14f;     /* success, ticks  */
}
Two rules to keep it readable 1. If you change --ink or --cream, update the matching --ink-rgb / --cream-rgb to the same colour in comma form — they power the subtle transparent tints.
2. --deep must stay dark and --on-accent must stay dark, whatever else you do. White text is drawn on --deep, and dark text is drawn on the bright accents.

Adding a sixth theme

  1. Copy any complete block in themes.css and rename the key, e.g. :root[data-theme="ocean"]{ … }
  2. Change the colours inside it.
  3. In every .html file, add a button to the theme panel: 
    <button class="swatch" data-theme="ocean" aria-pressed="false">
  <i></i>Ocean<span class="swatch__tick">✓</span>
</button>
  4. Give the swatch its little preview stripe in assets/css/style.css (search for .swatch[data-theme=): 
    .swatch[data-theme="ocean"]{--s1:#0b6fa4;--s2:#31d3c9;--s3:#ffd86b}

Editing content

Open any .html file in your editor. Sections are separated by banner comments so you can find them quickly:

<!-- ══ PROGRAMS ══ -->
<section class="section programs" id="programs">
  …
</section>

Golden rule: copy, don’t invent

To add another card, product, project, mentor or FAQ, copy an existing block from <article> (or <details>) to its closing tag, paste it below, and change the words. To remove one, delete the whole block. The grids re-flow automatically — you never have to touch the CSS.

The animated headline

Each word is its own span so it can fly in separately. Keep the --i numbers in order (0, 1, 2 …) — they set the delay:

<span class="line">
  <span class="word" style="--i:0">Build</span>
  <span class="word" style="--i:1">robots.</span>
</span>

Add class="word pop" for the highlighter-pen effect, or class="word grad" for gradient text.

products.html — Products

One <article class="prod"> is one product. The data-cat value must match one of the data-filter buttons above the grid, or the card will vanish when that filter is clicked.

<!-- filter button -->
<button class="chip-btn" data-filter="junior">Ages 9–12</button>

<!-- a card that this filter shows -->
<article class="prod" data-cat="junior">

The coloured panel behind each product emoji is set by prod__art--a through --f. Swap the letter for a different colour. The “Ask about this kit” link passes the product name to the contact form:

href="contact.html?item=Junior%20Arduino%20Lab#book"

Spaces must be written as %20. The contact form then pre-selects that product automatically.

gallery.html — Gallery

Each tile stores its pop-up text in data- attributes:

<article class="gal__tile" tabindex="0" role="button" data-cat="robots"
  data-title="Line-Follower Racer"
  data-maker="Zayn, 9 · Robot Lab"
  data-tech="Arduino · IR sensors · 3D printed chassis"
  data-story="The longer story that appears in the pop-up…">
  <div class="gal__art gal__art--a">🏎️</div>
  <div class="gal__meta">…</div>
</article>
Careful with apostrophes The data-story text sits inside double quotes. Do not use a double quote inside it — write &quot; instead, or use single quotes.

about.html — About Us

Story, four value cards, a timeline, and four mentor cards. Mentor avatar colours use theme tokens, so they follow whichever theme is active:

<div class="mentor__ava" style="--c:var(--grape)">S</div>

Valid values: var(--grape), var(--coral), var(--mint), var(--sky).

contact.html — Contact

Four info cards, the booking form, a decorative map panel, opening hours and an FAQ. The map is drawn in CSS — see the FAQ to swap in a real Google Map.

404.html — Error page

Point your host at this file so broken links land somewhere friendly. On Netlify, Vercel and GitHub Pages a file named 404.html in the root is picked up automatically. On Apache, add a line to .htaccess:

ErrorDocument 404 /404.html

FAQ accordions

These use native HTML — no JavaScript. Copy a block to add a question:

<details class="faq__item reveal" data-reveal="1">
  <summary>Your question here?</summary>
  <p>Your answer here.</p>
</details>

Make the contact form send email

Read this before you launch Out of the box the form validates the fields and shows a success message, but it does not deliver the message anywhere. HTML alone cannot send email. Connect one of the services below.

Option A — Formspree (easiest, free tier)

  1. Create a free form at formspree.io and copy your endpoint URL.
  2. In contact.html, find <form class="book__form" id="contactForm" and add the action: 
    <form class="book__form reveal" id="contactForm"
      action="https://formspree.io/f/YOUR_ID"
      method="POST" novalidate>
  3. In assets/js/main.js, find the contact-form block (section 10) and delete the line e.preventDefault(); together with the two lines that hide the form. The browser will then submit normally.

Option B — Keep the nice success message

To submit in the background and still show the built-in “Message received!” panel, replace the success part of the submit handler in assets/js/main.js with:

fetch(cForm.action, {
  method: "POST",
  body: new FormData(cForm),
  headers: { Accept: "application/json" }
}).then(function () {
  cForm.hidden = true;
  document.getElementById("contactDone").hidden = false;
});

Option C — Your own PHP host

Point the form at a PHP script and rename the file to contact.php:

<form action="send.php" method="POST">

Every field already has a name attribute (pname, pmail, pphone, cage, interest, msg), so $_POST['pmail'] works straight away.

Also on the Home page index.html has a shorter sign-up form near the bottom (id="trialForm"). It behaves the same way and needs the same treatment, or you can delete it and link to the contact page instead.

Fonts

Two Google Fonts are used: Fredoka for headings and Nunito for body text. Both are free for commercial use (SIL Open Font License).

Swapping them

Change the <link> in the <head> of all five pages, then update the two font stacks in assets/css/style.css:

body{ font-family:"Nunito", system-ui, sans-serif; }         /* body */
h1,h2,h3,h4,.brand__text,.btn{ font-family:"Fredoka", … }   /* headings */

Hosting the fonts yourself

If you need the site to work fully offline, or you must avoid third-party requests for privacy law reasons, download the two families from fonts.google.com, place the files in assets/fonts/, remove the Google <link> tags and add @font-face rules at the top of style.css.

Logo & favicon

Text logo

The logo is text plus a small inline robot. In the nav of every page:

<span class="brand__text">Curio<span>Maker</span></span>

The inner <span> is what gets the accent colour.

Using an image logo instead

Replace the whole <span class="brand__bot">…</span> block (the inline <svg>) with:

<img src="assets/img/logo.svg" alt="Your Brand" width="140" />

…and delete the <span class="brand__text"> line if your image already contains the name.

Favicon

Replace favicon.svg in the root folder, keeping the same filename. For wider device support you can also add a PNG:

<link rel="icon" href="favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="assets/img/icon-180.png" />

Using real photos

The template ships with zero image files on purpose — everything is CSS gradients, emoji and inline SVG. That keeps it fast, licence-free and instantly recolourable. Most buyers will want real photos of their own classes, though.

Replacing a product or gallery panel with a photo

Find the coloured panel:

<div class="gal__art gal__art--a">🏎️</div>

Replace it with:

<div class="gal__art">
  <img src="assets/img/project-1.jpg" alt="Line-follower robot"
       style="width:100%;height:100%;object-fit:cover" />
</div>
Photo tips Gallery panels are 4:3 and product panels are 16:10. Save JPGs around 1200 px wide, compress them at squoosh.app, and always write a real alt description — it matters for Google and for screen readers.
Photographs of children If you publish photos of real students, get written permission from a parent or guardian first. Many countries require it.

Scroll animation

Any element with class="reveal" fades and slides up when it scrolls into view. The number sets the order within its group:

<div class="card reveal" data-reveal="1">…</div>
<div class="card reveal" data-reveal="2">…</div>  <!-- appears slightly later -->

Add reveal to anything you create. To make something appear immediately, just leave the class off.

Parallax layers

Background shapes drift as you scroll. The data-speed value is how fast — 0.1 is subtle, 0.7 is dramatic:

<div class="blob blob--grape" data-speed="0.28"></div>
<span class="float float--gear" data-speed="0.55">⚙️</span>

Turning animation off

Delete class="reveal" and the data-speed attributes, or add this to the end of style.css:

.reveal{opacity:1 !important;transform:none !important}
Already handled for you Visitors who set “reduce motion” in their operating system get a static version automatically, and the site still displays correctly with JavaScript disabled.

Adding a new page

  1. Duplicate about.html and rename it, e.g. pricing.html.
  2. Change the <title> and meta description at the top.
  3. Edit the breadcrumb and page-hero heading.
  4. Delete the sections you do not need, keeping the nav, footer and the two <script> blocks.
  5. Add the link to the nav on all pages: 
    <a href="pricing.html">Pricing</a>
  6. On the new page only, mark it as current: 
    <a class="is-active" href="pricing.html">Pricing</a>

SEO checklist

  • Give every page a unique <title> — about 55 characters.
  • Give every page a unique <meta name="description"> — about 155 characters.
  • Keep exactly one <h1> per page (already set up that way).
  • Write real alt text on every photo you add.
  • Add social preview tags to each <head>:

<meta property="og:description" content="One sentence about you." />
<meta property="og:image" content="https://yoursite.com/assets/img/share.jpg" />

  • Submit your site to Google Search Console.

Pricing & Blog pages

pricing.html

Three plan cards, a billing toggle and a comparison table.

The toggle swaps every price between two values you set on the price element itself — there is no JavaScript to edit:

<b class="price" data-month="39" data-term="99">$39</b>

data-month shows when the switch is off, data-term when it is on. Type the same monthly figure between the tags so the page looks right before any JavaScript runs.

Changing the currency The $ is added by the script. In assets/js/main.js, find the pricing block (section 10b) and change "$" to your symbol. Remember to change the hard-coded $ in the HTML too.

Mark a plan as the highlighted one by adding plan--best and a ribbon:

<article class="plan plan--best">
  <span class="plan__tag">Most popular</span>

In a plan’s feature list, add class="no" to show a feature as not included:

<li class="no">Competition team</li>

blog.html

One <article class="post"> is one article. It uses the same filter system as the Products page — data-cat must match a data-filter button.

Add post--feature to make a card span the full width as the lead story:

<article class="post post--feature" data-cat="parents">

Pagination at the bottom is static. When you have enough posts, create blog-2.html and point the links at it.

blog-single.html

Duplicate this file for each article. Inside <div class="article__body"> you can use ordinary <h2>, <p>, <ul> and <blockquote>, plus two extras:

<!-- a highlighted tip box -->
<div class="callout">
  <b>Try this</b>
  <p>Your tip here.</p>
</div>

<!-- an inline figure with caption -->
<div class="article__fig post__art--b">🔍</div>
<p class="article__cap">Your caption.</p>

Swap post__art--a through --f for different panel colours, or replace the whole div with an <img> as described under Using real photos.

FAQ

The page looks unstyled — just black text on white.

The assets folder is missing or was moved. It must sit in the same folder as the HTML files.

My theme choice does not stick between pages.

You are opening the files by double-clicking (file://). Browsers isolate storage per file in that mode. It works normally once the site is on a web server.

Can I use a real Google Map?

Yes. Replace the whole <div class="map">…</div> block in contact.html with a Google Maps embed iframe, and add style="width:100%;height:100%;border:0" to the iframe.

How do I remove a whole page?

Delete the .html file, then remove its link from the nav and footer on the remaining pages.

Does it work in Internet Explorer?

No. It uses CSS custom properties and color-mix(), so it needs a modern browser: Chrome, Edge, Firefox or Safari from 2023 onward. IE reached end of life in 2022.

Can I use this for a school, nursery or coding bootcamp?

Yes — the layout suits any kids’ education business. Change the wording and the colour theme and it reads completely differently.

Is it a WordPress theme?

No, this is a plain HTML template. It can be converted to WordPress by a developer, but no WordPress version is included.
