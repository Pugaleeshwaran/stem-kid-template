PUT YOUR IMAGES HERE
====================

The template ships with no image files on purpose — every visual is a CSS
gradient, an emoji or inline SVG. That keeps it fast, license-free and
instantly recolourable by the theme switcher.

When you add your own photos, drop them in this folder and reference them as:

    assets/img/your-photo.jpg

RECOMMENDED SIZES
-----------------
  Gallery project panel   1200 x 900 px   (4:3)
  Product panel           1200 x 750 px   (16:10)
  About-page story panel  1000 x 920 px   (roughly square)
  Social share image      1200 x 630 px

TIPS
----
  * Compress before uploading — squoosh.app is free and excellent.
  * Aim for under 200 KB per photo.
  * Always write a real alt description on every <img>.
  * See documentation/index.html -> "Using real photos" for the exact
    HTML to paste in.

PERMISSION
----------
  If you publish photographs of real children, get written permission from a
  parent or guardian first. Many countries require it.
